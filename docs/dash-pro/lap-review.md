# Lap Review
The Lap Review pops up when you cross the line and sums up the lap you just completed: lap time, delta, sectors, fuel and more.

Set it up in the **Lap Review** tab:

1. **Choose the sessions.** Tick **Practice**, **Qualifying** and **Race** to show the Lap Review in each. Click a session to edit its layout; each one has its own.
2. **Choose the size.** **Strip** runs across the top of the dash, **Full Screen** covers it.
3. **Pick a layout and its modules.** Click a slot to choose a module, the same way you build a page.
4. **Copy to all sessions** when you want the same Lap Review everywhere.

The Lap Review's colors and how long it stays on screen are set in [Alerts & Notifications](./alerts.html).

See [Lap Review Modules](./modules.html#lap-review-modules) for the list of modules.
