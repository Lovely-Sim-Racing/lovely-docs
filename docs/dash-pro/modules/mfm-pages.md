# MFM Pages
Set a side column of the page's grid to **MFM** to give it a Multi Function Module: a tall panel with pages.

* By default it shows the MFM pages switched on for the sim in the Lovely Plugin's **Multi Function Modules** settings.
* Or pin it to one page, chosen in the layout editor.
