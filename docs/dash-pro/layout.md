# Layout & Pages
The **Pages & Layout** tab is where you build the dash itself: the pages it has, when each one shows, and what's on it.

## Pages
Every Preset can have as many pages as you need.

* **Add**, **Remove**, **Rename**, **Duplicate** and **Reorder** pages from the page list.
* Switch between pages on your device with the **Next Page** and **Previous Page** controls set in [Manage Devices & Controls](./concept.html#managing-your-devices).

A page is either **Modular**, built from modules, or **Full Screen**, a single full screen view such as the Relative, Standings or Map.

## Sessions
Pick the sessions each page shows in: **Practice**, **Qualifying** and **Race**. Each page only shows in the sessions you pick.

## Drag & Drop UI
Design each page in the layout editor:

* **Click a slot** to choose the module that goes there.
* **Drag and drop** modules to rearrange them.
* Choose whether the page shows the **Sidebar**, the **Topbar**, both or neither.
* Turn on **Preview Layout** to see the page live on the device selected at the top.

See [Modules](./modules.html) for everything you can place on a page.
